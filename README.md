# Hopes

Reflex Clicker adalah gim refleks sederhana berbasis Python/Tkinter yang dapat dijalankan di Windows. Tugas Anda adalah mengklik tombol yang bergerak secepat mungkin sebelum waktu habis.

## Cara menjalankan

1. Pastikan Python 3.10+ sudah terpasang di Windows (Tkinter sudah tersedia secara bawaan di instalasi resmi Python).
2. Unduh atau klon repositori ini.
3. Jalankan gim:

   ```bash
   python game.py
   ```

4. Tekan **Mulai**, lalu klik tombol kuning setiap kali berpindah. Gim akan berakhir setelah 30 detik dan menampilkan skor akhir.

## Catatan
- Resolusi jendela dan tata letak terkunci supaya tata letak tetap rapi.
- Jika ingin mengubah lama permainan, ubah nilai `game_duration` di `game.py`.
